# ADR-0029: 推論プレイブックの二経路配布と意思決定3閾値

## ステータス

採用（2026-07-06）

## 背景

### ladder は「検証の量」を規定するが「思考の質」を規定しない

ADR-0028 の難所エスカレーション ladder は、難所で発火すべき検証の量（L1-L4・票数・実行 arbiter）を規定する。一方、各検証の中でどう考えるか — 前提を疑う・生成と批判を分離する・リスク所在で裁定する等の思考の型 — は brain 層の暗黙知に留まり、配布物として構造化されていなかった。

### brain 層のみの配布では届かない利用者がいる

思考の型を OSS テンプレート brain（`brain/thinking.md`）だけに置くと、個人 brain を育てていない（`/setup` 未実行・silent ignore 運用の）利用者には届かない。ADR-0016 のフェイルセーフ設計（個人 brain 不在でも PJ brain だけで動く）の帰結として、brain 経路は到達保証がない。

### 「70%で動く」と「確証95%未満は断定しない」の干渉

テンプレート brain §1 の隣接する2基準は対象が異なる（判断=行動閾値 / 事実=断定閾値）が、その区別が無記載のため「70%だから検証を省く」「確証がないから確認に逃げる」の両誤読が可能だった。また「95%」という数値は自己申告不能な擬似精度で、実際に機能する判定器は CLAUDE.md ゲート2 の運用テスト（一次ソースを当該セッションで見たか）である。

## 検討内容

| 選択肢 | 評価 |
|--------|------|
| brain テンプレートのみ | 個人 brain 未育成の利用者に届かない。到達保証なし |
| rules のみ（常駐） | 全 PJ に届くが、9 ムーブ＋テンプレ全文の常駐は context-economy §3（retrieve > resident）に反する |
| **二経路（brain §0 概要 + docs 全文 + rules から参照）** | 概要表のみ常駐・全文は難所で Read。brain 未育成でも rules 経由で到達。常駐コスト最小 |

## 決定

### 1. 推論プレイブックを二経路で配布する

- **経路A（brain）**: テンプレート brain に §0「推論プロトコル」を追加（大原則5＋9ムーブ概要表）。`/setup` の初期コピーと `/adopt-sidekick-update` の差分提案で利用者の個人 brain に届く
- **経路B（機構）**: 全文（指示テンプレ付き）を `.claude/docs/reasoning-playbook.md` として配布し、`context-economy.md` §8（常駐 rules）から参照する。個人 brain の育成状態に依存せず、難所で必ず到達する

単一ソースは docs 側。brain §0 は概要（要約）であり、乖離時は docs が正。

### 2. 意思決定を対象別3閾値に再構成する

テンプレート brain §1「意思決定」を「**事実**（一次ソース確認の運用テスト・未確認は断定禁止）／**判断**（70%の確信で動く）／**不可逆**（確信度に関わらず確認）」の3対象に分離し、干渉の禁止（相互に言い訳として使わない）を明文化する。「確証95%未満は断定しない」の数値表現は、判定可能な運用テストに置換する。

### 3. 反証可能性ムーブのスコープを明示する

「外れうる断定を意図的に混ぜる」（ムーブ5）は校正用の仮説予言であり、「事実」ルールの例外であることをムーブ定義とスコープ注記に明記する（矛盾の常駐を防ぐ）。

## 理由

- **到達の冗長化**: ladder（rules・全PJ常駐）が発火点、playbook（docs・遅延）が中身、brain §0 が常駐サマリ。どの層が欠けても他の層で届く
- **文脈経済との整合**: 常駐は概要表のみ（context-economy §3）。全文は難所でのみロード
- **既存機構との接続**: R3 敵対検証はムーブ7の最低線として位置づけ、既存 ladder の運用を変えずに思考の質を上積みする

## 却下した案

- **skills 化（/reasoning 等）**: 実行を忘れる（半自動 curation の教訓）。難所検知（detect-hard-spot.sh + §8）という既存の発火点に接続する方が確実
- **CLAUDE.md への直接記載**: CLAUDE.md は規約（what to do）専用。思考の型（how to think)は brain / docs の責務（ADR-0013 の役割純化を維持）

## 影響

### 変更が入るファイル

- `brain/thinking.md`: §0 追加、§1 意思決定の3閾値化、§2 検証の作法追加
- `.claude/docs/reasoning-playbook.md`: 新規（配布物）
- `.claude/rules/context-economy.md`: §8 に参照追記
- `docs/decisions/README.md` / `CHANGELOG.md`

### 下流 PJ への配布

`/adopt-sidekick-update` で docs + rules が届く。個人 brain への §0 反映は差分提案のみ（ADR-0016 の上書き禁止運用を維持）。
