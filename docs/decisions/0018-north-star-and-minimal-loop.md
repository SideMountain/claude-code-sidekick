# ADR-0018: 北極星と最小ループ（3 動詞）

## ステータス

採用（2026-06-13）

## 背景

sidekick は skill / hook / rule / brain を多数備える。利用者が「どれをいつ使うか」を能動的に覚えるべき接点が多いほど、ハーネスの複雑さが利用者に転嫁され、テンプレートの価値を相殺する。

機能の網羅性と、利用者が意識すべき面積の小ささは、トレードオフの関係にある。網羅性を保ちながら利用者の認知負荷を最小化する基準が必要である。

## 決定

### 北極星

**下流はハーネスの複雑さを意識しない。組み合わせ不要・デフォルトのまま安全。**

利用者が能動的に学習・選択しなくても、デフォルト構成のまま安全side に倒れ、恩恵を受けられる状態を最上位の目標とする。設計判断はこの北極星に照らして評価する。

### 能動層は最小ループ（3 動詞）

利用者が日常で意識する接点を、次の最小ループに限定する。

```
/news（最新化） → 作業 → /close-chat（締め）
```

加えて週次の `/weekly-inventory`（棚卸し・知識還流）。

これ以外のスキルは**配管**（受動層）として位置づけ、README で能動的な使い方を教えない方向とする。配管は必要な局面で自動発火するか、最小ループのスキル内部から呼ばれる。

### 受動層が複雑さを吸収する

hook（session-start・PreToolUse ガード・PostToolUse 検知）と自動発火スキルが、利用者が意識しないところで複雑さを吸収する。利用者が覚える接点を増やさずに、安全性・品質・知識還流を成立させる。

## 理由

1. **怠惰の美徳**: 利用者が覚える接点を最小化し、残りは強制層・検知層で自動化する。手動を残すなら理由が要る
2. **仕組み化の 3 層（認知→強制→検知）**: 能動層（認知）を最小に絞り、強制層（hook）と検知層（棚卸し）に複雑さを寄せる
3. **デフォルト安全（ADR-0002 ブラックリスト方式）**: 危険なものだけ止め、それ以外は自動。利用者が許可リストを組み立てる必要がない

## 却下した案

- **全スキルを README で平等に教える**: 学習コストが増え、複雑さが利用者に転嫁される。網羅性の提示と利用者の認知負荷削減が両立しない
- **接点ゼロの完全自動**: 判断が必要な局面（PR マージ・本番操作・設計判断）で透明性と承認ゲートを失う。安全側に倒れない

## 影響

- README は最小ループ 3 動詞を中心に再構成する。他スキルは「必要時に発火する配管」として軽く扱う
- `/setup` の案内も最小ループ中心とする
- 評価者向けの設計思想ダイジェストにも北極星を反映する
- UI/UX ハーネス（ADR-0019）も受動層中心・opt-in で北極星に整合させる
