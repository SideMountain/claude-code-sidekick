# docs/migrations/ — 下流移行ガイド

ccs のリリースで下流 PJ に**手作業の移行**が必要になる変更（スキルの撤去・rename、設定キーの変更、ファイル配置の移動等）を、リリース単位のガイドとして残す場所。

## 規約

- 1 つの破壊的変更 = 1 ファイル。トピック名（例: `review-6to1-adapter.md`）で置く。
- 各ガイドは「何が変わったか / 前提 / 移行手順 / 撤去スケジュール」を含む。
- `oss-doc-authoring.md` に従い、経緯の時系列でなく**完成形の手順**を書く。

## ライフサイクル（意図する連携）

- `/adopt-sidekick-update` が取り込み時に、新規 or 更新された移行ガイドを案内する。
- `/release` がマイナー切り時に、deprecation を含むリリースへ該当ガイドの有無を促す。

（上記の自動連携は段階的に配線する。ガイド自体は連携の有無に関わらず本ディレクトリを正とする。）
