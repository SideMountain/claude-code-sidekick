# ワークフロー

## テスト実行の最適化

| タイミング | テスト範囲 | レビュー |
|---|---|---|
| ローカル開発中 | 変更に関連するテストのみ（スコープ限定） | なし |
| PR作成前 | 全テスト + 型チェック + ビルド | `/review`（動的スキップあり） |
| main マージ前 | 全テスト + 型チェック + ビルド + E2E | `/review`（全観点フル実行） |

- `TEST_COMMAND` が設定されている場合、ローカルでは `--grep` や `--filter` で対象を絞る
- 全テストがパスしなければ PR を作成しない（PR作成前ゲートで保証）
