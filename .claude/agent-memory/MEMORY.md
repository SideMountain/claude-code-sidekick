# Agent Memory（プロジェクトスコープ）

このディレクトリはサブエージェント（Agent ツールで起動される実行主体）が
セッションを跨いで蓄積する学習記録の共有スコープ。

## 用途

- レビューエージェントが蓄積する PJ 固有の false positive パターン
- scout エージェントが蓄積する外部ベストプラクティスのキャッシュ
- inventory エージェントが蓄積するタスク照合の学習結果

## ルール

- このファイルの先頭200行がエージェントのシステムプロンプトに注入される
- エージェントは自身のメモリを自由に読み書きできる
- 定期的な整理は `/weekly-review` で実施する
- PJ 固有の情報はこのスコープ、個人的な学習は `agent-memory-local/` に記録する

## 蓄積パターン

（エージェントが実行を重ねるごとに、ここにパターンが蓄積される）
